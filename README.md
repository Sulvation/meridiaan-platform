# meridiaan-platform
This repo contains a fictional company infrastructure platform for learning purposes, and goes hand-in-hand with the Labs repo.
The following topics will be covered in the project;
- IaC (bicep/terraform)
- CI/CD
- Ansible
- Logging/analytics
- Containers
- Kubernetes
- Reliability

The plan and labs have been created with AI, but all code is written by me and reviewed by AI. Any override is marked with a header and commit trailer.
Visual Studio Code Auto-complete is still enabled, as that's production relevenat in future production workloads.
Copilot autofix is disabled.
